## Proyecto 

Maqueta demo de un sistema kardex para un taller rectificador de culatas. (repuestos de culata) con ingreso de mercadería y normalizacion de repuestos.

## Stack — 100% JavaScript

    - Web: Javascript
    - Estilos: CSS
    - Base de datos: localstorage

## Flujo de Trabajo 

1. El usuario entra a ingresos.html.
2. Registra la entrada de nuevos productos (codigo, descripcion, unidades solicitadas y proveedor).
3. El sistema guarda la nueva compra, luego en la tabla de compras da la opcion de "Normalizar Pedido".
4. La página normalizacion.html permite ajustar el inventario real y darle la descripción interna que quiere el usuario.
5. Busqueda: El usuario puede ir a la pagina index.html para buscar repuestos por filtros: 
    -Anotaciones de numeros de piezas
    -Anotaciones de marcas
    -Procedencia del repuesto
    Esta pagina de busqueda tambien sirve para que el usuario pueda añadirle nuevas anotaciones a los repuestos.
